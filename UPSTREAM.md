# Source provenance

Awake is derived from [Limitless](https://github.com/leboonducoin/Limitless),
revision `1728d8bc7f50ffa8eb23f45fe5548dd199f5bb80` (2026-10-01 snapshot).
The original MIT license and third-party notices are preserved unchanged.

This is a separate native application. It is not derived from the unavailable
source code of the Amphetamine App Store application. Its application, helper,
CLI, preferences, journal and updater identities are isolated under
`io.github.oviron.Awake`. Release downloads target the independent Awake repository.

Local changes beyond identity isolation are documented in `README.md`.
